# Exploratory Data Analysis (EDA)

## What Is EDA?

Exploratory Data Analysis (EDA) is an approach used to:
- Analyze data  
- Summarize main characteristics  
- Understand the dataset better  
- Discover relationships between variables  
- Identify important variables for a problem  

---

## Goal of EDA

Answer key questions about the data.

Example:
- Which features have the biggest impact on car price?  

---

## What You Learn in EDA

### 1. Descriptive Statistics

- Describe basic features of data  
- Provide summaries of:
  - Data distribution  
  - Central tendency (mean, median)  
  - Variability (std, range)  

---

### 2. Grouping Data

- Use `groupby()` to:
  - Organize data into groups  
  - Compare different categories  
  - Transform datasets for analysis  

---

### 3. ANOVA (Analysis of Variance)

- Statistical method used to:
  - Compare differences between groups  
  - Analyze variation in data  
- Helps determine if variables significantly affect the target  

---

### 4. Correlation

- Measures relationship between variables  
- Shows how one variable changes with another  

---

### 5. Advanced Correlation

- **Pearson Correlation**  
  - Measures linear relationship between variables  

- **Correlation Heatmaps**  
  - Visual representation of correlations  
  - Helps quickly identify strong relationships  

---

## Key Insight

EDA helps you:
- Understand your dataset  
- Detect patterns and relationships  
- Select important features  
- Prepare data for modeling
